# 📊 BI Dorneles Soluções

Dashboard interativo desenvolvido em Python para análise de performance de leads, faturamento e gestão de funil de vendas.

## 🚀 Funcionalidades
- **Visão Geral:** Métricas de faturamento, ticket médio e conversão.
- **Análise de Perdas:** Identificação de motivos de desistência e gargalos.
- **Integração:** Conexão direta com Google Sheets para atualização em tempo real.
- **Filtros Dinâmicos:** Filtros por operador, status, cidade e período.

## 🛠️ Tecnologias
- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [Pandas](https://pandas.pydata.org/)
- [Plotly](https://plotly.com/python/)
- [Google Sheets API](https://developers.google.com/sheets/api)

## 📋 Como rodar
1. Instale as dependências: `pip install -r requirements.txt`
2. Certifique-se de ter o arquivo `credenciais-dorneles.json` na raiz.
3. Execute: `streamlit run app.py`
